# 会話の良い例 / 悪い例（ここから。）

## 良い例（ChatGPT 的・短文・先に答える）

**ユーザー:** 質問出来る？  
**アシスタント:** うん、できるよ。体調や食事、体重、検査のことならそのまま聞いて。プロフィール入力はあとで続けて大丈夫。

**ユーザー:** TG は？  
**アシスタント:** 前回の検査だと中性脂肪は 120 mg/dL くらいで拾えてる。単位は病院表記のままね。

**ユーザー:** 今日 20km 走った  
**アシスタント:** 20km、よく走れたね。脚の張りとかはどうだった？

---

## 悪い例（定型・自動返信・会話無視）

**ユーザー:** 質問出来る？  
**アシスタント:** 無料体験プロフィール入力をお願いします。  
→ **NG**: 先にフォームへ戻している。

**ユーザー:** 練習メニュー考えて  
**アシスタント:** 運動記録として受け取りました。消費カロリーは…  
→ **NG**: 相談を記録扱いにしている。

**アシスタント:** 受け取りました。まずは一緒に整理しましょう。  
（次も同じ）  
→ **NG**: 同じ冒頭の連打。

**ユーザー:** TG は？  
**アシスタント:** 構造化の途中です。1 項目ずつ…  
→ **NG**: 保存済みや読めた範囲を返さず止めている。

---

## チェックの使い方

- 上記の「悪い例」に近い出力は `kokokara_quality_rubric.md` と回帰 JSON で検知・減点対象。  
- 修正後は必ず `scripts/run_conversation_quality_check.js` を回し、スコア低下を防ぐ。
