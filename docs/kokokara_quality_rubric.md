# ここから。伴走品質ルーブリック

この文書は「ここから。」の継続改善で、機能修正ごとに品質を測るための基準です。

## 評価の考え方

- ベースは ChatGPT の自然な会話感
- そこに牛込先生らしい温かさ、強み起点、安全優先を足す
- 自動返信っぽさを減らし、困っている人が次に進みやすい導線を優先する

## カテゴリ

- Technical
  - 送信失敗、接続失敗、画像送信失敗
  - 血液検査抽出失敗、動作解析分岐失敗
  - グラフ崩れ、無限ループ
- UX
  - チャット欄の狭さ
  - 上部余白の多さ
  - 入力欄の見えにくさ
  - 自動スクロール不備
  - 過去履歴導線の不自然さ
- Conversation
  - 定型文反復
  - 直接回答不足
  - 説明過多
  - 困り時の丁寧さ不足
  - 案内文への逃げ

## 最初の必須チェック

### A. 無料体験/プロフィール入力ループ

- 同じ案内文を 2 回以上連続で返したら警告
- ユーザー質問に答えず入力フォーム誘導へ戻したら警告

### B. 定型文反復

- 同一前置き・同一締めの連続率を測る
- 類似返答が連続したら警告

### C. 直接回答率

- 短い質問では、先に質問へ回答しているかを判定
- 先頭が案内文だけなら減点

### D. 困り時の丁寧説明

- 困りシグナルがある時、短すぎる命令だけになっていないかを確認
- 理由付きの案内が無い場合は減点

## スコアリング（MVP）

- ベース 100 点
- 重大違反（ループ、未回答誘導）: -30
- 中程度違反（定型反復、直接回答不足）: -10
- 軽微違反（丁寧さ不足）: -5

## 判定目安

- PASS: 80 点以上、重大違反 0
- WARN: 70-79 点または重大違反 1
- FAIL: 69 点以下または重大違反 2 以上

## 運用

- 修正ごとに `npm run quality:check` を実行
- FAIL は原則マージしない
- 再発したケースは `tests/conversation_regression_cases.json` に追加
